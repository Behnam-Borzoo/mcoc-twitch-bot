# MCOC Twitch Bot — راهنمای راه‌اندازی

## 🚀 نصب سریع روی VPS (توصیه‌شده)

اگه پروژه رو روی GitHub آپلود کردی، فقط این یه خط رو روی VPS بزن:

```bash
curl -o deploy.sh https://raw.githubusercontent.com/YOUR_USERNAME/mcoc-twitch-bot/main/deploy.sh && bash deploy.sh
```

یا اگه فایل `deploy.sh` رو دستی روی سرور آپلود کردی:
```bash
bash deploy.sh https://github.com/YOUR_USERNAME/mcoc-twitch-bot.git
```

این اسکریپت خودش:
- ✅ Node.js و PM2 رو نصب می‌کنه (اگه نباشن)
- ✅ پروژه رو از GitHub می‌کشه پایین
- ✅ پکیج‌ها رو نصب می‌کنه
- ✅ فایل `.env` می‌سازه و برات با nano بازش می‌کنه تا پرش کنی
- ✅ Bot رو با PM2 اجرا می‌کنه و برای اجرای دائمی (حتی بعد ری‌استارت سرور) آماده می‌کنه

بعد از اجرای اسکریپت، فقط دستوری که در آخر چاپ می‌شه (زیر `pm2 startup`) رو کپی/پیست کن و اجرا کن — این آخرین قدمه.

## 📖 نصب دستی (قدم‌به‌قدم)

اگه ترجیح می‌دی خودت دستی انجام بدی:
اگه هنوز نصب نکردی، از اینجا دانلود کن: https://nodejs.org (نسخه LTS)

## مرحله ۲: دانلود پروژه
این پوشه (`mcoc-bot`) رو روی کامپیوترت کپی کن.

## مرحله ۳: نصب پکیج‌ها
داخل پوشه پروژه، ترمینال باز کن و بزن:
```
npm install
```

## مرحله ۴: گرفتن OAuth Token
1. برو به https://twitchapps.com/tmi/
2. با اکانتی که می‌خوای Bot باهاش لاگین کنه وارد شو (می‌تونه اکانت خودت باشه یا یه اکانت جدا مثلاً BehnamBorzoo_Bot)
3. یه توکن بهت میده که با `oauth:` شروع میشه — اونو کپی کن

## مرحله ۵: تنظیم فایل .env
فایل `.env.example` رو کپی کن و اسمش رو بذار `.env`، بعد مقادیر داخلش رو با اطلاعات خودت پر کن:
- `TWITCH_BOT_USERNAME` = یوزرنیم اکانتی که باهاش لاگین کردی
- `TWITCH_OAUTH_TOKEN` = توکنی که از مرحله ۴ گرفتی
- `TWITCH_CHANNEL` = اسم کانال خودت (بدون #)
- `DISCORD_LINK` = لینک دیسکورد کانالت
- `CURRENT_CHAMP` و `CURRENT_RANK` = هر وقت عوض شد دستی آپدیت کن

## مرحله ۶: اجرا
```
npm start
```
اگه همه چی درست باشه، توی ترمینال می‌بینی که Bot به کانالت وصل شده. حالا برو توی چت خودت تست کن:
```
!champ
!rank
!bg
!discord
!commands
```

## چطور AI Auto-reply کار می‌کنه؟

فقط کافیه توی چت یه سؤال بنویسی — نیازی به کامند خاص نیست:
```
which champ counters serpent?
کدوم چمپیون خوبه برای بی جی؟
```
Bot خودش تشخیص میده که این یه سؤاله (با `؟`/`?` یا کلمات سؤالی مثل who/what/کدوم/چطور شروع میشه) و با Claude API جواب میده.

اگه بخوای صریح‌تر سؤال بپرسی هم می‌تونی از `!ask` استفاده کنی:
```
!ask best counter for Nick Fury?
```

### تنظیمات مهم
- `ANTHROPIC_API_KEY` رو توی `.env` بذار (از https://console.anthropic.com)
- `AI_COOLDOWN_SECONDS` — هر چند ثانیه یک نفر حداکثر می‌تونه یه جواب AI بگیره (پیش‌فرض ۲۰ ثانیه). این برای جلوگیری از اسپم و کنترل هزینه API هست.
- همچنین حداقل ۴ ثانیه فاصله بین هر جواب AI به‌طور کلی رعایت میشه (حتی برای کاربرای مختلف)، که چت شلوغ نشه.

### نکته هزینه 💰
هر بار که AI جواب میده، از API Key شما هزینه کم میشه (خیلی کمه، مدل استفاده‌شده Haiku که ارزون‌ترین مدله). اگه چت خیلی شلوغه، `AI_COOLDOWN_SECONDS` رو بیشتر کن.

## چطور Bot رو بعداً آپدیت کنی؟
اگه بعداً کد رو عوض کردی (مثلاً من فایل جدیدی برات فرستادم)، کافیه دوباره روی VPS بزنی:
```bash
cd mcoc-twitch-bot
bash deploy.sh
```
خودش تشخیص می‌ده پروژه از قبل هست، آپدیتش می‌کنه و PM2 رو دوباره راه می‌ندازه. فایل `.env` دست‌نخورده می‌مونه.

## دستورات مفید PM2
```bash
pm2 status              # وضعیت Bot
pm2 logs mcoc-bot        # لاگ‌های زنده (برای دیباگ)
pm2 restart mcoc-bot     # ری‌استارت دستی
pm2 stop mcoc-bot        # خاموش کردن موقت
```

هر وقت تست کردی و کار کرد، خبر بده بریم سراغ فاز بعدی.
