## 🚀 نصب سریع روی VPS (توصیه‌شده)

اگه پروژه رو روی GitHub آپلود کردی، فقط این یه خط رو روی VPS بزن:

```bash
curl -o deploy.sh https://github.com/Behnam-Borzoo/mcoc-twitch-bot/blob/main/deploy.sh && bash deploy.sh
```

یا اگه فایل `deploy.sh` رو دستی روی سرور آپلود کردی:
```bash
bash deploy.sh https://github.com/Behnam-Borzoo/mcoc-twitch-bot.git
```

این اسکریپت خودش:
- ✅ Node.js و PM2 رو نصب می‌کنه (اگه نباشن)
- ✅ پروژه رو از GitHub می‌کشه پایین
- ✅ پکیج‌ها رو نصب می‌کنه
- ✅ فایل `.env` می‌سازه و برات با nano بازش می‌کنه تا پرش کنی
- ✅ Bot رو با PM2 اجرا می‌کنه و برای اجرای دائمی (حتی بعد ری‌استارت سرور) آماده می‌کنه

بعد از اجرای اسکریپت، فقط دستوری که در آخر چاپ می‌شه (زیر `pm2 startup`) رو کپی/پیست کن و اجرا کن — این آخرین قدمه.

1. برو به https://twitchapps.com/tmi/

## چطور AI Auto-reply کار می‌کنه؟

فقط کافیه توی چت یه سؤال بنویسی — نیازی به کامند خاص نیست:
```
which champ counters serpent?
کدوم چمپیون خوبه برای بی جی؟
```
Bot خودش تشخیص میده که این یه سؤاله (با `؟`/`?` یا کلمات سؤالی مثل who/what/کدوم/چطور شروع میشه) و با Claude API جواب میده.

اگه بخوای صریح‌تر سؤال بپرسی هم می‌تونی از `!ask` استفاده کنی:
```
!ask best counter for Nick Fury?
```

### تنظیمات مهم
- `ANTHROPIC_API_KEY` رو توی `.env` بذار (از https://console.anthropic.com)
- `AI_COOLDOWN_SECONDS` — هر چند ثانیه یک نفر حداکثر می‌تونه یه جواب AI بگیره (پیش‌فرض ۲۰ ثانیه). این برای جلوگیری از اسپم و کنترل هزینه API هست.
- همچنین حداقل ۴ ثانیه فاصله بین هر جواب AI به‌طور کلی رعایت میشه (حتی برای کاربرای مختلف)، که چت شلوغ نشه.

### نکته هزینه 💰
هر بار که AI جواب میده، از API Key شما هزینه کم میشه (خیلی کمه، مدل استفاده‌شده Haiku که ارزون‌ترین مدله). اگه چت خیلی شلوغه، `AI_COOLDOWN_SECONDS` رو بیشتر کن.

## چطور Bot رو بعداً آپدیت کنی؟
اگه بعداً کد رو عوض کردی (مثلاً من فایل جدیدی برات فرستادم)، کافیه دوباره روی VPS بزنی:
```bash
cd mcoc-twitch-bot
bash deploy.sh
```
خودش تشخیص می‌ده پروژه از قبل هست، آپدیتش می‌کنه و PM2 رو دوباره راه می‌ندازه. فایل `.env` دست‌نخورده می‌مونه.

## دستورات مفید PM2
```bash
pm2 status              # وضعیت Bot
pm2 logs mcoc-bot        # لاگ‌های زنده (برای دیباگ)
pm2 restart mcoc-bot     # ری‌استارت دستی
pm2 stop mcoc-bot        # خاموش کردن موقت
```

هر وقت تست کردی و کار کرد، خبر بده بریم سراغ فاز بعدی.

## راه‌اندازی روی VPS (بدون نیاز به PC) 🚀

از اونجایی که با iPad/iPhone کار می‌کنی و Termius داری، این ساده‌ترین مسیره:

### مرحله ۱: پروژه رو به GitHub بفرست
1. یه Repo جدید بساز (ترجیحاً **Private**، چون بعداً رمزها رو دستی روی سرور می‌ذاری نه توی گیت)
2. فایل‌های `index.js`, `package.json`, `.gitignore`, `deploy.sh` رو آپلود کن (از GitHub وب یا اپ)
3. فایل `.env` رو آپلود **نکن** — این حاوی توکن و API Key هست و باید فقط روی خود سرور باشه

### مرحله ۲: با Termius به VPS وصل شو
مثل همیشه با IP و یوزر/پسورد یا SSH Key سرورت وصل شو.

### مرحله ۳: اسکریپت نصب رو اجرا کن
داخل ترمینال VPS بزن:
```bash
curl -o deploy.sh https://raw.githubusercontent.com/USERNAME/mcoc-twitch-bot/main/deploy.sh
chmod +x deploy.sh
./deploy.sh https://github.com/USERNAME/mcoc-twitch-bot.git
```
(به‌جای `USERNAME` اسم گیت‌هابت رو بذار — اگه Repo رو Private کردی، اول باید یه Personal Access Token بسازی و توی لینک کلون از اون استفاده کنی، بگو راهنماییت کنم)

این اسکریپت خودش:
- Node.js و PM2 رو نصب می‌کنه (اگه نباشن)
- پروژه رو از GitHub می‌کشه پایین
- فایل `.env` رو می‌سازه و با **nano** بازش می‌کنه تا مقادیر واقعی (Token, API Key, نام کانال) رو دستی پر کنی
- Bot رو با **PM2** اجرا می‌کنه — یعنی حتی اگه Termius رو ببندی یا صفحه iPad خاموش بشه، Bot همچنان روشن می‌مونه

### مرحله ۴: راه‌اندازی خودکار بعد از ری‌استارت سرور
در پایان اسکریپت یه خط دستور بهت میده — همون رو کپی/پیست کن تا اگه سرور یه وقت ری‌استارت شد، Bot خودش دوباره روشن بشه.

### دستورات مفید بعد از نصب
```bash
pm2 status              # وضعیت Bot
pm2 logs mcoc-bot        # لاگ‌های زنده
pm2 restart mcoc-bot --update-env   # بعد از تغییر .env
```

هر وقت تست کردی، بگو تا بریم سراغ فاز بعدی (Follow/Sub alerts).

## فاز ۳: Follow / Sub Alerts

### مرحله ۱: ثبت یه App روی Twitch
1. برو به https://dev.twitch.tv/console/apps (با همون اکانتی که Streamer هستی وارد شو)
2. **Register Your Application**
3. **Name**: هرچی دوست داری (مثلاً `BehnamBorzoo MCOC Bot`)
4. **OAuth Redirect URLs**: بذار `https://twitchtokengenerator.com/callback` (چون از این سایت برای گرفتن توکن استفاده می‌کنیم)
5. **Category**: Chat Bot
6. بعد از ساخت، یه **Client ID** بهت میده — کپیش کن، توی `.env` می‌خوایمش (`TWITCH_CLIENT_ID`)

### مرحله ۲: گرفتن Access Token با اسکوپ درست
1. برو به https://twitchtokengenerator.com
2. گزینه **Custom Scope Token** رو انتخاب کن
3. این دو اسکوپ رو تیک بزن:
   - `moderator:read:followers`
   - `channel:read:subscriptions`
4. **Generate Token** بزن و با اکانت Twitch خودت (صاحب کانال) تایید کن
5. یه **Access Token** بهت میده — همینو توی `.env` بذار (`TWITCH_ACCESS_TOKEN`)

⚠️ این توکن معمولاً بعد از چند ساعت/روز منقضی میشه. اگه یه وقت Alert ها کار نکردن، احتمالاً باید یه توکن جدید بگیری (بعداً می‌تونیم Refresh خودکار هم اضافه کنیم).

### مرحله ۳: مقادیر رو توی .env پر کن
```
TWITCH_CLIENT_ID=...
TWITCH_ACCESS_TOKEN=...
```

### مرحله ۴: آپدیت روی VPS
از توی پوشه پروژه روی VPS (توی Termius):
```bash
git pull
npm install
nano .env    # مقادیر جدید رو اضافه کن، Ctrl+O و Ctrl+X برای ذخیره
pm2 restart mcoc-bot --update-env
pm2 logs mcoc-bot
```
اگه توی لاگ خط `✅ Subscribed to channel.follow` و `✅ Subscribed to channel.subscribe` رو دیدی، یعنی وصل شده. حالا هر Follow/Sub جدید یه پیام خودکار توی چت میفته.

هر وقت تست کردی، بگو بریم سراغ فاز بعدی (Poll سیستم برای رأی‌گیری Champion در BG).

## ردیاب Win/Loss زنده BG

چون Bot به خود بازی دسترسی نداره، خودت با یه کامند سریع بعد از هر فایت نتیجه رو ثبت می‌کنی:

| کامند | کی می‌تونه | کار |
|---|---|---|
| `!win` | مدیر/برودکستر | یه Win ثبت می‌کنه |
| `!loss` | مدیر/برودکستر | یه Loss ثبت می‌کنه |
| `!record` | همه | رکورد فعلی + Win Rate + Streak رو نشون میده |
| `!resetrecord` | مدیر/برودکستر | رکورد رو صفر می‌کنه (مثلاً شروع استریم جدید) |

وقتی به ۳، ۵، ۱۰، ۱۵ یا ۲۰ Win پشت‌سرهم برسی، Bot خودش با 🔥🔥 جشن می‌گیره.

رکورد توی فایل `record.json` ذخیره میشه — یعنی اگه Bot ری‌استارت بشه (مثلاً سرور Reboot بشه) رکورد از دست نمی‌ره. این فایل عمداً به گیت‌هاب Push نمیشه (توی `.gitignore` هست) چون مخصوص هر سروره.

### آپدیت روی VPS
```bash
git pull
pm2 restart mcoc-bot --update-env
```

نکته: اگه دوست داشتی هر روز/هر استریم رکورد از صفر شروع بشه، یادت باشه اول استریم `!resetrecord` بزنی.

هر کسی توی چت پیام بده و توی ۱۰ دقیقه اخیر «فعال» حساب بشه، هر ۱۰ دقیقه یک‌بار ۱۰ امتیاز می‌گیره (هر دو عدد قابل تنظیم توی `.env`).

| کامند | کی می‌تونه | کار |
|---|---|---|

## Refresh خودکار توکن Twitch

الان دیگه لازم نیست هر چندروز دستی بری توکن جدید بگیری. ولی برای اینکه این کار کنه، باید یه‌بار یه توکن *به اسم اپلیکیشن خودت* بگیری (نه سایت واسطه) که Refresh Token هم داشته باشه.

### مرحله ۱: گرفتن Client Secret
1. برو https://dev.twitch.tv/console/apps → همون اپلیکیشنی که قبلاً ساختی رو باز کن
2. **New Secret** بزن — یه رشته میده که فقط **یه‌بار** نشونش میده، همون لحظه کپیش کن

### مرحله ۲: گرفتن توکن با Refresh Token واقعی
1. برو https://twitchtokengenerator.com → **Custom Scope Token**
2. دنبال گزینه‌ای مثل **"Use Your Own Client ID/Secret"** یا بخش Advanced بگرد و Client ID و Client Secret خودتو وارد کن
   - اگه پیدا نکردی، بگو برات روش دستی (بدون این سایت) رو هم توضیح بدم
3. اسکوپ‌های `moderator:read:followers` و `channel:read:subscriptions` رو تیک بزن
4. Generate کن و با اکانت Twitch تایید کن
5. این‌بار هم **Access Token** و هم **Refresh Token** واقعی می‌گیری — هر دو رو کپی کن

### مرحله ۳: پر کردن .env
```
TWITCH_CLIENT_ID=...
TWITCH_CLIENT_SECRET=...
TWITCH_ACCESS_TOKEN=...
TWITCH_REFRESH_TOKEN=...
```

### مرحله ۴: آپدیت روی VPS
```bash
git pull
pm2 restart mcoc-bot --update-env
pm2 logs mcoc-bot
```
اگه توی لاگ `✅ Auto token refresh فعاله.` رو دیدی، یعنی از این به بعد Bot خودش هر وقت لازم باشه توکن رو تمدید می‌کنه — دیگه نیازی به دخالت دستی نیست.

**نکته:** اولین باری که Bot اجرا میشه، یه فایل `twitch_token.json` می‌سازه و از اون به بعد همیشه از همون استفاده می‌کنه (نه از `.env`). اگه یه‌وقت خواستی توکن‌های `.env` رو دوباره جایگزین کنی، اول این فایل رو روی VPS پاک کن:
```bash
rm twitch_token.json
pm2 restart mcoc-bot --update-env
```

## چندزبانگی، خوش‌آمدگویی، یادآوری فالو و پایان استریم

نیازی به تنظیمات جدید نیست — فقط `git pull` و `pm2 restart` کافیه.

### چندزبانه (آلمانی، انگلیسی، فارسی)
سیستم AI Auto-reply (فاز ۲) حالا خودش تشخیص میده سؤال به چه زبونیه (آلمانی/انگلیسی/فارسی) و دقیقاً به همون زبون جواب میده. نیازی به کاری از طرف تو نیست.

### خوش‌آمدگویی شروع استریم
هر بار که Bot به کانال وصل میشه (یعنی وقتی `pm2 start` یا `pm2 restart` می‌زنی)، خودش یه پیام خوش‌آمد سه‌زبونه می‌فرسته:
```
👋 Stream is live! Welcome everyone! | خوش اومدید! | Willkommen im Stream!
```
اگه می‌خوای این پیام دقیقاً موقع شروع خود استریم (نه فقط وصل شدن Bot) فرستاده بشه، بهتره Bot رو دقیقاً همون لحظه‌ای که استریم رو شروع می‌کنی روشن کنی (یا `pm2 restart mcoc-bot` بزنی).

### یادآوری فالو/حمایت
هر ۲۰ دقیقه (قابل تنظیم با `FOLLOW_REMINDER_INTERVAL_MINUTES`) یه پیام یادآوری فالو می‌فرسته، به‌نوبت انگلیسی، فارسی، بعد آلمانی.

### پایان استریم
قبل از تموم کردن استریم، توی چت بزن:
```
!endstream
```
Bot این‌طوری جواب میده:
- اگه توی اون سشن فالوور جدید داشتی: اسم همه‌شون رو میگه و تشکر می‌کنه
- بعدش یه جمله‌ی بسته‌ی گرم می‌فرسته: «🙏 Thanks everyone for an awesome stream — see you next time! ❤️»
- اگه فالوور جدیدی نبود، فقط همون جمله‌ی تشکر رو می‌فرسته

فقط مدیر یا برودکستر می‌تونه این کامند رو بزنه، تا کسی اشتباهی یا شوخی وسط چت اجراش نکنه.

**نکته:** لیست فالوورهای جدید الان توی فایل `new_followers.json` روی خود سرور ذخیره میشه — یعنی حتی اگه Bot بین شروع و پایان استریم Restart بشه، لیست از دست نمی‌ره. این فایل هم مثل بقیه فایل‌های داده (`record.json`, `points.json`) توی `.gitignore` هست.
